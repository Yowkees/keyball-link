# Keyball Link

Keyball39/44/61 向けのWebベースキーマップ設定ツールです。
WebHID API を使用してブラウザから直接キーボードと通信します。

## 🌐 アプリを使う

**👉 https://keyball-link.yoho-3418.workers.dev**

インストール不要。上記URLを **Chrome または Edge** で開くだけで使えます。

> ⚠️ **Safari / Firefox は非対応です**（WebHID API に対応していないため）

## 機能

- **キーマップ編集**（全レイヤー対応・ドラッグ&ドロップ）
- **Mod-Tap / Layer-Tap**（1つのキーにタップとホールドで別動作）
- **マクロ**（キー入力を記録して再生・タイミング記録対応）
- **トラックボール設定**（CPI・スクロール・アクセラレーション）
- **LED設定**（エフェクト・色・明るさ）
- **JSONエクスポート / インポート**（設定のバックアップ・共有）
- **LED診断 / テストマトリクス**（動作確認）
- **ファームウェア書き込み**（ブラウザから直接）

## 使い方

1. Keyball を USB でパソコンに接続する
2. アプリを Chrome / Edge で開く
3. 「キーボードに接続」を押してデバイスを選択
4. キーをクリックして割り当てを変更
5. 右上の「保存する」で確定

## ⌨️ macOSで @ などの記号が正しく入力できない場合

macOS が Keyball を US 配列と誤認識することがあります。
アプリの **「詳細設定」タブ → 「macOS キーボードタイプ設定」** から、
ワンクリックでコピーできる修正コマンドを実行してください（初回のみ）。

## 対応キーボード

- Keyball44
- Keyball61

## 開発

```bash
npm install      # 依存パッケージのインストール
npm run dev      # 開発サーバー起動（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に出力）
```

## 対応ブラウザ

Chrome / Edge（WebHID 対応ブラウザが必要）
