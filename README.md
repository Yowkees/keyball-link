# Keyball Link

Keyball39/44/61 向けのWebベースキーマップ設定ツールです。
WebHID API を使用してブラウザから直接キーボードと通信します。

## 🌐 アプリを使う

**👉 https://keyball-link.shiroganelab.com**

インストール不要。上記URLを **Chrome または Edge** で開くだけで使えます。

> ⚠️ **Safari / Firefox は非対応です**（WebHID API に対応していないため）

## 機能

- **キーマップ編集**（全レイヤー対応・ドラッグ&ドロップ・Undo/Redo）
- **レイヤーの並べ替え**（タブをドラッグ、切替キーの番号も自動で付け替え）
- **Mod-Tap / Layer-Tap**（1つのキーにタップとホールドで別動作）
- **タップダンス**（タップ回数で動作を変える）
- **マクロ**（キー入力を記録して再生・タイミング記録対応）
- **トラックボール設定**（CPI・スクロール・加速・自動マウスレイヤー）
- **ジェスチャー**（トラックボールを振って上下左右に操作を割り当て。タップ/長押し兼用キー・レイヤー連動対応）
- **LED設定**（エフェクト・色・明るさ ※LED版ファームのみ）
- **詳細設定**（Tapping Term・Permissive Hold などをキー単位で調整）
- **JSONエクスポート / インポート**（設定のバックアップ・共有)
- **テストマトリクス**（キースイッチの動作確認）
- **ファームウェア書き込み**（ブラウザから直接）

## 使い方

1. Keyball を USB でパソコンに接続する
2. アプリを Chrome / Edge で開く
3. 「キーボードに接続」を押してデバイスを選択
4. キーをクリックして割り当てを変更
5. 右上の「保存」で確定

## ファームウェアについて

本アプリ専用のファームウェア（QMKベース）が必要です。「ファームウェア」タブからブラウザで直接書き込めます。

各機種とも容量の都合で2バージョンあります:

| バージョン | 内容 |
|---|---|
| 通常版 | メディアキー・ジェスチャー・キー単位詳細設定など全機能（LEDなし） |
| LED版 | LED点灯対応の最小機能版（メディアキー・ジェスチャーなし） |

ファームウェアのソースコードは [keyball-link-firmware](https://github.com/ineno771/keyball-link-firmware) で公開しています。

## ⌨️ macOSで @ などの記号が正しく入力できない場合

macOS が Keyball を US 配列と誤認識することがあります。
アプリの **「詳細設定」タブ → 「macOS キーボードタイプ設定」** から、
ワンクリックでコピーできる修正コマンドを実行してください（初回のみ）。

## 開発

```bash
npm install      # 依存パッケージのインストール
npm run dev      # 開発サーバー起動（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に出力）
```
