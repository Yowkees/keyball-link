# Keyball Web Configurator

Keyball39/44/61 向けのWebベースキーマップ設定ツールです。  
WebHID API を使用してブラウザから直接キーボードと通信します。

## 機能

- キーマップ編集（全レイヤー対応）
- Mod-Tap / Layer-Tap 設定
- トラックボール設定（CPI・スクロール・アクセラレーション）
- LED設定
- タップダンス設定
- テストマトリクス（キー入力確認）
- ファームウェア書き込み

## 対応ブラウザ

Chrome / Edge（WebHID対応ブラウザが必要）

## 対応キーボード

- Keyball39
- Keyball44
- Keyball61
